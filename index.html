このアプリでできること・できないこと

スマホのカメラで「隠しカメラのレンズの光り方」と「暗視用の赤外線ライト」を探す補助ツールです。

見つけやすい小型カメラのレンズ（ライトを当てると点で光る）、暗視カメラの赤外線ライト、録画中を示す小さなランプ
見つけにくい盗聴器（音だけを拾う機器）。電波で音を飛ばすものが多く、カメラには写りません。磁気モードは「電子部品がある場所」の手がかりになる程度です。
できない電波の受信、Wi-Fi・Bluetooth機器の一覧表示。これらはブラウザの仕組み上できません。
できないメーカー名・製品名の特定。理由は下の「場所の画像の見方」を参照してください。
「何も出なかった＝安全」ではありません。目視・手で触れての確認と組み合わせてください。強い不安がある場合は専門の調査業者に相談してください。

はじめに

  1. 画面下の「スキャン」を開き、モードを選びます。
  2. 「スキャン開始」を押し、カメラの使用を許可します。
  3. iPhoneは共有ボタン→「ホーム画面に追加」、Androidはメニュー→「ホーム画面に追加」で、アプリのように使えます。

場所の画像（発見レポート）の見方

怪しい点が見つかると、スキャン画面に場所を示す画像が自動で出て、記録タブにも保存されます。「差分判定」の後や、「記録」ボタンを押した時にも作られます。

  • オレンジの円と「①ここ」：怪しい点の位置です。複数あれば①②③と番号が付きます。
  • オレンジの枠の拡大図：①の周りを数倍に拡大した映像です。円とは線でつながっています。
  • 白い点線の枠：AIが見分けた「物」（時計、テレビ、観葉植物、ぬいぐるみなど）とその名前です。
  • 画像の下の帯：画像だけを人に見せても伝わるよう、場所と物を文字で書き込んでいます。

画面の下には、点ごとに次の3つが文字で表示されます。

場所画面のどこか（例：画面の左上・横 23%・縦 18%）
付いている物どの物のどのあたりか（例：時計（推定）の上部右寄り）
形・特徴光り方から読み取れる形（例：ピンホール型レンズに近い小さな点／赤外線LEDがまとまって並ぶ）

メーカー名・製品名が出ない理由

カメラ越しに見えるのは「レンズが光を跳ね返した点」だけで、どの会社のどの製品でも同じように見えます。製品を見分ける手がかり（型番・刻印・基板）は本体を取り外さないと確認できません。推測で製品名を出すと誤った判断につながるため、このアプリでは表示しません。製品の特定は、警察や専門の調査業者が取り外した後に行います。

物の名前について

物の名前は端末の中で動くAIによる推定です。火災報知器、コンセント、USB充電器、換気扇などはAIが名前を付けられないため「推定できませんでした」と出ます。その場合は画像の位置と拡大図で確認してください。

レンズ反射モード（基本）

カメラのレンズは、光を当てると来た方向へ光を跳ね返す性質があります。ライトとカメラを同じ向きにして部屋を見回すと、レンズだけが「小さな点」で光って見えます。

  1. 部屋の照明を消し、カーテンを閉めます。暗いほど見つけやすくなります。
  2. 「ライト」をオンにします（使えない機種は下の「困ったとき」参照）。
  3. スマホを胸〜目の高さで持ち、ゆっくり横に動かしながら部屋を一周します。距離は1〜3mが目安です。
  4. 動かしても同じ位置で光り続ける点にはオレンジの円が付きます。
  5. 円が付いたら近づき、「差分判定」を押します。ライトを自動で点けたり消したりして、反射（レンズの可能性）か、自分で光っている物（LEDなど）かを見分けます。
  6. 「赤フィルタ」をオンにすると、周りが暗く沈み、レンズの光が目立ちます。

赤外線モード（暗視カメラ探し）

夜でも映る防犯・盗撮カメラは、人の目に見えない赤外線ライトを出しています。スマホの前面カメラは赤外線が写る機種が多いので、これを使います。

  1. 部屋を真っ暗にします。
  2. まず動作テスト：テレビのリモコンを前面カメラに向けてボタンを押します。紫〜白く光れば、この端末で赤外線が見えます。
  3. 画面を自分に向けたまま、カメラ側を部屋に向けてゆっくり見回します。
  4. 紫っぽい、または白い光の点が並んでいる場所（リング状の点の集まりが多い）に印が付きます。
リモコンの光が写らない端末では、このモードは使えません。その場合は別のスマホや、古いデジカメを試してください。

磁気モード（盗聴器の補助）

スマホの磁気センサーで、電子部品やスピーカー、電源回路の近くで磁気が強くなる場所を探します。

  1. 何もない場所で「計測開始」→「ここを基準にする」を押します。
  2. コンセント、延長コード、置き時計、ぬいぐるみなどの表面を、スマホでゆっくりなぞります。
  3. 基準との差が大きくなるとオレンジ色になり、音の間隔が短くなります。
このモードは Android の Chrome で、設定を有効にした場合だけ使えます（管理者マニュアル参照）。iPhone では使えません。金属の家具や家電でも反応するため、反応＝盗聴器ではありません。

画面の印の見方

薄い白の円：光る点の候補。まだ判断できない段階です。
オレンジの円：要確認。何フレームも続けて光った点です。近づいて目で確かめてください。
オレンジの四角：差分判定で「ライトを当てた時だけ光った」点。レンズの可能性が高めです。
白の点線の四角：差分判定で「ライトを消しても光っていた」点。LEDなど自分で光る物です。録画ランプの場合もあります。

怪しい物を見つけたら

  1. 触らない・壊さない・外さない。証拠が失われたり、設置者に気づかれたりします。
  2. 「記録」で画像を残し、メモ欄に場所や時刻を書きます。「報告書を保存」で一式を1つのファイルにできます。
  3. ホテル・職場・賃貸なら管理者へ、身の危険を感じる場合は警察へ相談してください（警察相談専用電話 #9110、緊急時は 110）。

よくある誤検知

  • ネジの頭、金属のフチ、ガラス、鏡、水滴、光沢のあるプラスチック
  • 家電の電源ランプ、火災報知器のランプ（差分判定で「発光」と出ます）
  • 窓の外の街灯や車のライト

見分け方：少し横に移動して角度を変えます。レンズは角度を変えても点のまま光り続け、ネジや水滴は光り方が大きく変わったり消えたりします。

困ったとき

カメラが映らないブラウザの設定でこのページのカメラを「許可」にしてください。ほかのアプリがカメラを使っている場合は閉じてください。
ライトが押せないiPhone など、ブラウザからライトを操作できない機種です。別のスマホのライトや懐中電灯を、カメラのすぐ横から同じ向きに当てて使ってください（差分判定はその場合は使えません）。
候補が多すぎる感度を下げる、照明を消す、光沢のある物から離れる、を試してください。
何も出ない感度を上げる、ズームで寄る、ゆっくり動かす、を試してください。
画面が暗くなるスキャン中は画面が消えないようにしていますが、機種によっては効きません。省電力モードを切ってください。

磁気モードを有効にする（Android）

  1. Chrome のアドレス欄に chrome://flags と入力します。
  2. 「Generic Sensor Extra Classes」を検索し、Enabled にして再起動します。
  3. アプリの磁気モードで「計測開始」を押します。

公開手順

A. GitHub Pages（無料・おすすめ）

  1. GitHub で新しいリポジトリを作り、index.html（と、あれば sw.js）をアップロードします。
  2. Settings → Pages → Branch を main / root にして保存します。
  3. 数分後に表示される https://〜.github.io/〜/ を利用者に配ります。

B. Netlify Drop（登録だけで最短）

  1. app.netlify.com/drop を開き、フォルダごとドラッグします。発行されたURLを配ります。

C. 社内のWebサーバー

  1. HTTPS が有効な公開ディレクトリに index.html（と、あれば sw.js）を置きます。
Google Apps Script（GAS）の Webアプリは画面が枠の中で動く仕組みのため、カメラの許可が通らないことが多く、おすすめしません。

データの扱い

  • カメラ映像は端末内で解析するだけで、どこにも送信しません。物体認識もAIの部品（プログラムと学習済みデータ）を端末に読み込んで、端末の中で動かします。
  • 外部からの読み込みは、フォント（Google Fonts）と物体認識の部品（cdn.jsdelivr.net／storage.googleapis.com）のみです。どちらも読めなくても、検知と場所の画像は動きます（物の名前が出なくなるだけ）。初回に読み込んだ後はオフラインでも使えます。
  • 記録画像・メモ・チェックリストの状態は、端末のブラウザ内（localStorage）に保存します。
  • 利用者が消すには、記録画面の「すべて削除」か、ブラウザの「サイトデータを削除」を使います。
  • サーバーにログは残りません（ファイル配信のアクセスログを除く）。

更新手順

  1. index.html などを修正します。
  2. sw.js を置いている場合は、2行目の VERSION の数字を1つ上げます。これを忘れると、利用者の端末に古い版が残ります。
  3. サーバーのファイルを置き換えます。利用者はアプリを2回開き直すと新しい版になります。

配布前の動作確認

  1. 公開URLを Android と iPhone で開き、カメラ許可が出ること。
  2. 暗い部屋で、別のスマホのカメラレンズ（電源オフでよい）を2m先に置き、オレンジの円が付くこと。
  3. Android で差分判定を押し、そのレンズが「反射」、テレビの電源ランプが「発光」と出ること。
  4. 赤外線モードでテレビのリモコンを押し、光点に印が付くこと。
  5. オレンジの円が出た時に、場所の画像（円・拡大図・下の説明帯）が自動で表示されること。置き時計の上にレンズを置き、「時計（推定）の〜」と出ること。
  6. 記録→報告書の保存ができること。機内モードでもアプリが開くこと。

検知の仕組み（技術メモ）

  1. 映像を横320ピクセルに縮め、明るさの地図を作ります。
  2. 各点の明るさを「周りの平均」と比べ、周りより飛び抜けて明るく、かつ小さく丸い点だけを候補にします（細長い反射や大きな照明は除外）。
  3. 候補をフレーム間で追いかけ、続けて現れたものを「要確認」にします。手ブレで一瞬光るだけの物はここで落ちます。
  4. 差分判定はライトの点灯時と消灯時の候補を比べ、点灯時だけにある点を「反射」、両方にある点を「発光」とします。
  5. 赤外線モードでは、紫寄り・白寄りの色をした点の評価を上げます。
  6. 場所の画像：要確認の点が出た瞬間の映像を保存し、物体認識AI（COCO-SSD、80種類の物を識別）で物の位置を調べ、点がどの物の枠の中・近くにあるかを文章にします。拡大図は縮小前の元の解像度から切り出します。

既知の制約

  • 盗聴器の検知は原理的に限定的です。確実に調べるには電波を受信する専用の探知機が必要です。
  • 最近の赤外線カットフィルタ付きの前面カメラでは、赤外線モードが働きません。
  • レンズが黒いカバーやハーフミラーの裏にある場合、反射が弱く見つからないことがあります。
  • メーカー名・製品名は特定できません。外から見える光り方に製品ごとの違いがないためです。
  • 物体認識が名前を付けられるのは一般的な80種類の物のみで、火災報知器・コンセント・換気扇などは対象外です。
  • ブラウザからは Wi-Fi・Bluetooth 機器の一覧を取得できません。Wi-Fi カメラを疑う場合はルーターの管理画面で接続機器を確認してください。
